# Старые версии личных страниц

Вёрстка `personal.html`, `resume.html` и `freelance.html` до редизайна в et-115 (коммит `233a6d9`).

Лежат вне `src/main/resources`, поэтому не попадают в jar и не отдаются приложением.
Картинки в них ссылаются на `/images/...` и `/assets/...` — при открытии файла напрямую они не подгрузятся.
